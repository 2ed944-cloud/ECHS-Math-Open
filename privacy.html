Privacy

Current platform model: Phase 2 is local-first. No student account or central learner database is required. Learning history remains in browser storage unless the user explicitly exports a report file.

Information stored locally

The platform may store a student name or nickname, grade, daily goal, selected courses, lesson bookmarks, completion marks, practice and test attempts, topic mastery, Mistake Bank records, spaced-review dates, learning sessions, streaks, achievements, local class rosters, assignment links and imported learning reports.

Student reports and teacher workspaces

Exporting a student learning report or teacher workspace creates a JSON file on the user’s device. Importing one of these files is an explicit action by the student, teacher or family. The static platform does not automatically upload those files.

Information not collected by this release

This GitHub Pages release does not include a platform-operated account system, advertising tracker, payment system or central analytics database. It does not sell learner information. The local sync adapter does not contact Firebase, Supabase or another cloud provider.

External resources

Some lessons link to external video, graphing, document or publisher services. Opening an external service is subject to that provider’s privacy terms.

Service worker and offline storage

The installable web application caches platform files and may cache previously requested pages and question payloads. Cached files can be removed through browser site-data or application settings.

Future cloud accounts

If cloud accounts, live classrooms or cross-device synchronization are enabled later, this notice must be updated before production use. The new notice must identify the provider, data fields, lawful purpose, access controls, retention, deletion and school approval.

Managing local data

The Student Dashboard can reset student learning history while preserving teacher workspace data. The Teacher Dashboard can export or restore its local workspace. Browser settings can remove all ECHS Mathematics site data.
