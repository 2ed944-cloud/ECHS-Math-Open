Privacy

Account-free platform: this open edition does not create learner, teacher, family or administrator accounts. Learning history remains in browser storage unless the user explicitly exports a file.

Information stored locally

The platform may store optional display preferences, a nickname, grade or level, daily goal, selected courses, lesson bookmarks, completion marks, practice and test attempts, topic mastery, Mistake Bank records, spaced-review dates, sessions, streaks and achievements.

Exported progress files

Exporting learning progress creates a JSON file on the user’s device. Importing or sharing that file is an explicit action by the user. The static platform does not automatically upload exported files.

Information not collected

This GitHub Pages release has no account system, public registration, advertising tracker, payment system or central learner database. It does not send learning progress to Firebase, Supabase or another cloud provider.

External resources

Some lessons link to external video, graphing or document services. Opening an external service is subject to that provider’s privacy terms.

Service worker and offline storage

The installable web application caches platform files and may cache previously requested pages and question payloads. Cached files can be removed through browser site-data or application settings.

Managing local data

The Progress page can reset learning history stored in this browser. Browser settings can also remove all ECHS Mathematics Open site data.
