Sources and publication boundaries

Important: course-aligned practice is not automatically an official AP question. Course Practice and the AP Practice Banks use different source rules, labels, data stores and publication gates.

ECHS-created material

Original lessons, explanations, diagrams, practice questions and assessments created for the ECHS learning environment.

Imported source collections

Practice records retained with source, edition, bank, chapter, pool and audit metadata. Friendly display labels never remove canonical provenance.

AP practice archive

Separately indexed records governed by source, transcription, mathematical, answer, media, KaTeX and curriculum-mapping verification gates.

Attribution and provenance

Canonical records retain available information about the source family, publication, edition, year, page or question number, source asset, import batch and audit history. A visual redesign must never erase provenance.

AP publication gate

Archive records may enter open practice only after the repository’s independent release conditions are satisfied. Indexed, incomplete or review-required records remain restricted or redacted and are excluded from scoring.

Imported-bank publication gate

A source collection is described as complete only when expected counts, chapter payloads, unique identifiers, answer references and required media packages pass validation. Original duplicate variants may be retained when present in the source.

Permissions

Availability in this open repository does not automatically grant permission to redistribute third-party or restricted assessment content. Users should follow applicable licences, institutional permissions and source terms.

Corrections

Source, transcription, answer, figure or attribution corrections preserve the original record ID and audit trail. Verified content must not be silently overwritten.
